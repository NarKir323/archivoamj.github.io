# Seguridad

## Reportar una vulnerabilidad

No publiques detalles de una vulnerabilidad en un issue público.

Envía el reporte a `aaronmj2010@gmail.com` e incluye:

- la página o archivo afectado;
- una descripción clara del problema;
- pasos mínimos para reproducirlo;
- el impacto que observaste.

Se confirmará la recepción y se evaluará el reporte antes de publicar detalles.

## Alcance

Este repositorio contiene un sitio estático publicado mediante GitHub Pages. No
recibe contraseñas, pagos ni datos personales mediante formularios.
